# J-Bridge Mail Assistant

일본어 거래처 메일을 입력하면 OpenAI API로 요청사항, 긴급도, 내부 확인사항, 회신 전 체크리스트, 일본어 답장 초안을 정리하는 업무 보조 웹앱입니다.

이 프로젝트는 일본 고객/협력사 대응, SCM, 생산관리, 품질관리, 기술지원 업무에서 반복적으로 발생하는 메일 확인 과정을 줄이는 것을 목표로 만들었습니다.

## 주요 기능

- 일본어 거래처 메일 분석
- 문의 유형 분류
- 거래처 요청사항 요약
- 긴급도와 회신 기한 정리
- 내부 확인 부서 제안
- 회신 전 체크리스트 생성
- 일본어 답장 초안 작성
- 답장 초안의 한국어 뜻 제공

## 실행 방법

1. `.env.example` 파일을 복사해 `.env` 파일을 만듭니다.
2. `.env` 파일에 OpenAI API 키를 입력합니다.

```env
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-4.1-mini
```

3. 아래 명령어로 실행합니다.

```bash
npm start
```

또는 Windows에서는 `start.cmd`를 실행해도 됩니다.

4. 브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:8787/
```

## 주의사항

- `.env` 파일은 GitHub에 올리면 안 됩니다.
- 입력한 메일 내용은 분석을 위해 OpenAI API로 전송됩니다.
- AI가 작성한 회신 초안은 실제 발송 전 반드시 사람이 검토해야 합니다.
- 첨부파일 분석 기능은 포함되어 있지 않습니다.

## 포트폴리오 설명

이 프로젝트는 단순한 웹페이지 제작보다, AI를 실제 직무 흐름에 연결하는 활용 능력을 보여주기 위한 포트폴리오입니다. 일본어 커뮤니케이션 역량과 컴퓨터공학 기반의 도구 제작 경험을 결합해, 한일 비즈니스 메일 대응을 더 빠르고 정확하게 돕는 업무 보조 도구로 기획했습니다.
